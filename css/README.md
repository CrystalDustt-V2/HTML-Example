# CSS Course

The **CSS course** teaches you how to style the HTML pages you already know
how to build. CSS (**Cascading Style Sheets**) controls colors, fonts, sizes,
spacing, and layout. It has **ten lessons** followed by a **final project**.

```
Learn → See → Write → Practice → Check → Build
```

## Before you start

- You have finished the [HTML course](../html/README.md), or you already know
  the basics of HTML (elements, attributes, classes, and ids).
- You can create and save files, and you have a web browser.
- You do **not** need JavaScript or any tools beyond a text editor.

## How to use this course

For every lesson, follow the same routine:

1. **Learn** — read the lesson `README.md`.
2. **See** — open `example.html` in your browser and read its code
   (the CSS lives in a `<style>` block in the `<head>`).
3. **Write & Practice** — follow `exercise.md` and write your own code.
4. **Check** — open `solution.html` only after you have tried, and compare.

## Final project

After the ten lessons, build the
[Final Project — Styled Personal Website](final-project/README.md): take the
personal website you built in the HTML course and give it a complete look with
one external `style.css`.

## What's next?

JavaScript is not part of this repository (yet). Once you are comfortable with
HTML and CSS, a JavaScript course is a natural next step — but you are
already in a great position: you can structure pages (HTML) and style them
(CSS). Build something of your own and experiment.
