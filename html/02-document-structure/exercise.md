# Exercise — A Complete Valid HTML Document

## 🎯 Goal

Write a complete, valid HTML document **from scratch** — without copying the
example. Type every line yourself; that is how the structure sticks.

## 📚 What You Learned

- `<!DOCTYPE html>`
- `<html lang="en">`
- `<head>` with `<meta charset="UTF-8">` and `<title>`
- `<body>`

## 📝 Task

1. Create a new file called `my-first-document.html`.
2. Write the complete document skeleton by hand: `<!DOCTYPE html>`, `<html>`,
   `<head>`, and `<body>`.
3. Give the page a meaningful `<title>` (for example "My First Document").
4. Inside the `<body>`, write one `<h1>` heading and one `<p>` paragraph of
   your choice.
5. Open the file in your browser and check:
   - The heading and paragraph appear on the page.
   - The browser tab shows your title.

## Requirements

- [ ] `<!DOCTYPE html>` is the very first line of the file
- [ ] The document has exactly one `<html>` element with `lang="en"`
- [ ] The document has a `<head>` containing `<meta charset="UTF-8">` and a `<title>`
- [ ] The `<title>` is inside the `<head>` (not the `<body>`)
- [ ] The document has a `<body>` with one `<h1>` and one `<p>`
- [ ] Every tag is closed in the correct order

## 💡 Hint

The example in this lesson's `example.html` is a valid document. Compare your
file with it line by line if you get stuck — but try to write yours from memory
first.

## ⭐ Challenge

Add a `<meta name="description" content="...">` tag to the `<head>`. A
description is a short summary of the page that search engines may show in
their results. Write a description that fits your page.

## ✅ Solution

Open `solution.html` **after** you have attempted the exercise and compare your
work. Your document does not need to be identical — it just needs to be valid
and complete.
