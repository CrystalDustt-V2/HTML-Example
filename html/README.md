# HTML Course

The **HTML course** teaches you the practical fundamentals of HTML — the
language that structures every web page. It has **ten lessons** followed by a
**final project**.

```
Learn → See → Write → Practice → Check → Build
```

## Before you start

- You have never written HTML before — perfect.
- You can create and save files, and you have a web browser.
- You do **not** need CSS, JavaScript, or any tools beyond a text editor.

## How to use this course

For every lesson, follow the same routine:

1. **Learn** — read the lesson `README.md`.
2. **See** — open `example.html` in your browser and read its code.
3. **Write & Practice** — follow `exercise.md` and write your own file.
4. **Check** — open `solution.html` only after you have tried, and compare.
