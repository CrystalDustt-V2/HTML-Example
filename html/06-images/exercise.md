# Exercise — A Gallery with Meaningful Alt Text

## 🎯 Goal

Practice `src`, `alt`, relative paths, external URLs, and sizing by building a
small gallery page.

## 📚 What You Learned

- `<img>` with `src` and `alt`
- Relative paths (`images/...`)
- External image URLs (`https://...`)
- `width` and `height`

## 📝 Task

1. Create a new file called `gallery.html` in the `06-images` folder.
2. Build a page about a theme you choose (animals, food, places, colors…).
3. Include at least **three** images:
   - At least two images from the local `images` folder using relative paths.
   - At least one image from an external website using a full URL (pick any
     image URL you like).
4. Give **every** image a meaningful `alt` text that describes what the image
   shows — not "image 1".
5. Resize at least one image with `width` and `height` attributes.

## Requirements

- [ ] The page is a complete, valid HTML document
- [ ] It contains at least three `<img>` elements
- [ ] At least two images use relative paths (`images/...`)
- [ ] At least one image uses an external URL
- [ ] Every image has an `alt` attribute with a real description
- [ ] At least one image has `width` and `height` attributes

## 💡 Hint

The local images in this lesson's `images` folder are simple colored shapes —
use them to practice relative paths first. The alt text for
`images/red-circle.svg` could be "A red circle".

## ⭐ Challenge

Add a paragraph next to one of your images that links to the page where you
found the image (an `<a>` around the text, pointing at the image's URL).

## ✅ Solution

Open `solution.html` **after** you have attempted the exercise and compare your
work. Any page with three correctly written images is a correct answer.
