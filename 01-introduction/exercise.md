# Exercise — Your First HTML Page

## 🎯 Goal

Write your very first HTML page: a short **personal introduction** about you.

## 📚 What You Learned

- What HTML is and what it does
- Elements, tags, opening and closing tags
- Attributes
- HTML comments

## 📝 Task

1. Create a new file called `introduction.html` in the `01-introduction` folder
   (or anywhere you like).
2. Start from the `example.html` file you just studied: copy it, or write your
   own from scratch.
3. Change the page so that it introduces **you**. You can include:
   - A heading with your name
   - One or two paragraphs about yourself (hobbies, interests, favorite food…)
   - A comment explaining something on the page
4. Save the file and open it in your browser (double-click the file, or drag it
   into your browser window).

## Requirements

- [ ] The page has the same structure as `example.html` (it includes
      `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`)
- [ ] The `<title>` says something about your page
- [ ] The page has a heading (`<h1>`) with your name or a title
- [ ] The page has at least two paragraphs (`<p>`) about you
- [ ] The page contains at least one comment (`<!-- ... -->`)
- [ ] Every element has a matching closing tag

## 💡 Hint

If you are stuck, open `example.html`, then change only the text inside the
tags. Keeping the structure the same is a perfectly good way to start.

## ⭐ Challenge

Add a second small page called `hobbies.html` that lists your hobbies in a few
paragraphs. Link from `introduction.html` to `hobbies.html` — you will learn
exactly how links work in [Lesson 05](../05-links/README.md), so use
`<a href="hobbies.html">` and don't worry if it does not look fancy yet.

## ✅ Solution

Open `solution.html` **after** you have attempted the exercise and compare your
work. Your page does not need to match it exactly — there are many correct
answers.
