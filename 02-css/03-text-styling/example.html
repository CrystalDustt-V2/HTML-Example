Why typography matters

"Good typography makes reading easy — bad typography makes reading a chore."

This page uses Georgia for the main heading and Arial for everything else. The line height is 1.6, which gives each line of text a little breathing room.

Warning: the heading above is written in uppercase using CSS — the HTML still contains normal text.

Try changing the font-family rule on body to monospace and refresh. The whole page switches to a typewriter look, without touching the HTML at all.
