# HTML-Example

Learn HTML **and** CSS by reading short explanations, studying working
examples, and — most importantly — writing your own code.

**HTML-Example** is a small, beginner-friendly repository with two courses:

1. **[HTML course](01-html/README.md)** — the practical fundamentals of HTML.
2. **[CSS course](02-css/README.md)** — styling those pages with CSS.

It is deliberately small: it does **not** cover JavaScript, frameworks, or
build tools. Every lesson follows the same path:

```
Learn → See → Write → Practice → Check → Build
```

---

## Who is this for?

This repository is for you if you:

- Have never written HTML or CSS before
- Have little or no programming experience
- Know how to create and edit files
- Have a web browser (Chrome, Firefox, Edge, or Safari)
- Want to *write* code, not just read about it

## Prerequisites

- A text editor (VS Code is recommended, but any editor works)
- A web browser
- The ability to create and save files

That's all. You do **not** need JavaScript, Node.js, npm, Git, or any build
tools. Plain HTML and CSS are enough to complete every lesson and both final
projects.

## How to use this repository

1. Start with **Lesson 01 of the HTML course** and work through the lessons
   **in order**. Each lesson builds on the previous ones.
2. For every lesson, follow the same routine:

   1. **Learn** — read the `README.md` explanation.
   2. **See** — open `example.html` in your browser and read its code.
   3. **Write & Practice** — follow the instructions in `exercise.md` and write
      your own file from scratch.
   4. **Check** — open `solution.html` **after** you have tried the exercise,
      and compare your work with it.

3. When you have finished the ten HTML lessons, build the
   [HTML Final Project](01-html/final-project/README.md): a personal website in
   plain HTML.
4. Then start the **CSS course** and style that same website. Finish with the
   [CSS Final Project](02-css/final-project/README.md).
5. Tick the boxes in the [progress checklist](#progress-checklist) below as
   you go.

> **Tip:** your solution does not need to look exactly like `solution.html`.
> There are many correct answers. Use the solution to learn from, not to copy.

## Learning path

```
HTML 01 → 02 → … → 10 → HTML Final Project
                            ↓
CSS  01 → 02 → … → 10 → CSS Final Project
```

Work through the lessons in this order. Concepts are introduced exactly when
they are needed, and exercises only use things you have already learned.

## Final projects

- **[HTML Final Project](01-html/final-project/README.md)** — after the ten HTML
  lessons, build a simple **personal website** that uses headings, paragraphs,
  text formatting, links, images, lists, tables, forms, semantic HTML, and
  comments — all in plain HTML.
- **[CSS Final Project](02-css/final-project/README.md)** — after the ten CSS
  lessons, style that personal website: colors, typography, the box model,
  links, lists, positioning, flexbox, and styled forms and tables — all from
  one external `style.css`.
