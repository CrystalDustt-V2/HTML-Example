# HTML-Example

Learn HTML by reading short explanations, studying working examples, and — most
importantly — writing your own code.

**HTML-Example** is a small, beginner-friendly repository that teaches the
practical fundamentals of HTML. It is deliberately small: it does **not** cover
CSS, JavaScript, frameworks, or build tools. Every lesson follows the same path:

```
Learn → See → Write → Practice → Check → Build
```

---

## Who is this for?

This repository is for you if you:

- Have never written HTML before
- Have little or no programming experience
- Know how to create and edit files
- Have a web browser (Chrome, Firefox, Edge, or Safari)
- Want to *write* HTML, not just read about it

## Prerequisites

- A text editor (VS Code is recommended, but any editor works)
- A web browser
- The ability to create and save files

That's all. You do **not** need CSS, JavaScript, Node.js, npm, Git, or any build
tools. Plain HTML is enough to complete every lesson and the final project.

## How to use this repository

1. Start with **Lesson 01** and work through the lessons **in order**. Each
   lesson builds on the previous ones.
2. For every lesson, follow the same routine:

   1. **Learn** — read the `README.md` explanation.
   2. **See** — open `example.html` in your browser and read its code.
   3. **Write & Practice** — follow the instructions in `exercise.md` and write
      your own HTML file from scratch.
   4. **Check** — open `solution.html` **after** you have tried the exercise,
      and compare your work with it.

3. When you have finished all ten lessons, build the
   [Final Project](final-project/README.md): a personal website that combines
   everything you learned.
4. Tick the boxes in the [progress checklist](#progress-checklist) below as you
   go.

> **Tip:** your solution does not need to look exactly like `solution.html`.
> There are many correct answers. Use the solution to learn from, not to copy.

## Learning path

```
01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → Final Project
```

Work through the lessons in this order. Concepts are introduced exactly when
they are needed, and exercises only use things you have already learned.

## Final project

After the ten lessons, build the [final project](final-project/README.md): a
simple **personal website** that uses headings, paragraphs, text formatting,
links, images, lists, tables, forms, semantic HTML, and comments — all in plain
HTML. The goal is to demonstrate your HTML knowledge, not visual design.
