# Exercise — A Structured School Page

## 🎯 Goal

Practice headings, paragraphs, line breaks, and horizontal rules by building a
small "school" page with clear structure.

## 📚 What You Learned

- Headings `<h1>` to `<h6>` and heading hierarchy
- Paragraphs `<p>`
- Line breaks `<br>`
- Horizontal rules `<hr>`

## 📝 Task

1. Create a new file called `school.html`.
2. Build a complete HTML document about a school (yours, imagined, or inspired
   by the example). Structure it with headings:
   - One `<h1>` with the school name
   - `<h2>` sections such as *History*, *Teachers*, and *Contact*
   - At least one `<h3>` subsection (for example *Our campus* under *Contact*)
3. Use paragraphs for the text and one or two `<hr>` lines to separate
   sections.
4. In the *Contact* section, use `<br>` to put the address on separate lines.

## Requirements

- [ ] The page is a complete, valid HTML document
- [ ] It uses exactly one `<h1>`
- [ ] It uses at least two `<h2>` headings
- [ ] It uses at least one `<h3>` heading below an `<h2>`
- [ ] It uses at least four `<p>` paragraphs
- [ ] It uses at least one `<br>` (inside a paragraph)
- [ ] It uses at least one `<hr>` (between sections)

## 💡 Hint

Open `example.html` and use it as a map. You do not need new content ideas —
simply change the school name, details, and address to make it yours.

## ⭐ Challenge

Add a *Daily Schedule* section that lists three classes — one for each of
`<h4>`, `<h5>`, and `<h6>` — with a short paragraph under each. Use this
opportunity to see how the smaller headings look on a real page.

## ✅ Solution

Open `solution.html` **after** you have attempted the exercise and compare your
work. As long as your page meets the requirements, your answer is correct.
