# Final Project — Personal Website

Congratulations — you have finished all ten lessons! Now it is time to combine
everything into one project: your own **personal website**.

## 🎯 Goal

Build a simple personal website that demonstrates the HTML skills you learned.
The goal is to show your *knowledge of HTML*, not to create visual design — no
CSS, no JavaScript, plain HTML only.

## 📚 What you will use

- Proper document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Headings (`<h1>`–`<h6>`) and paragraphs (`<p>`)
- Text formatting (`<strong>`, `<em>`, `<mark>`, `<small>`, …)
- Links (`<a>`), including one that opens in a new tab
- Images (`<img>` with `alt`)
- Lists (`<ul>`, `<ol>`, nested lists)
- A table (`<table>`)
- A form (`<form>` with at least three different field types)
- Semantic HTML (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`,
  `<aside>`, `<footer>`)
- Comments (`<!-- ... -->`)

## 📝 Task

1. Open `starter.html` and read it — it is a skeleton with comments that tell
   you exactly where each part goes.
2. Build your own `my-website.html` (start from the starter or from scratch)
   with these sections:
   - **Header** with your name and a small navigation (`nav`)
   - **About** — who you are, using headings, paragraphs, and at least three
     different text-formatting elements
   - **Projects** — at least two items, each in an `article`, with an image
     (`images/` in this folder has placeholders you can use) and a description
   - **Skills** — a list (bulleted, numbered, or nested)
   - **Schedule** — a small table (for example your weekly study plan)
   - **Contact** — a form with a name field, an email field, and one more
     field of your choice (dropdown, textarea, date, …)
   - **Aside** — a side block with a fun fact or a favorite quote
   - **Footer** — copyright line and at least two links
3. Add at least **three comments** explaining your choices.

## Requirements

- [ ] The page is a complete, valid HTML document
- [ ] It uses semantic elements: `header`, `nav`, `main`, `section`,
      `article`, `aside`, `footer`
- [ ] Exactly one `<h1>` (your name or site title)
- [ ] At least three different text-formatting elements (for example
      `strong`, `em`, `mark`)
- [ ] At least two links; at least one opens in a new tab (`target="_blank"`)
- [ ] At least two images, each with meaningful `alt` text
- [ ] At least one list and one nested list
- [ ] One table with `thead` and `tbody`
- [ ] A form with at least three fields, each with a connected `label`
- [ ] At least three HTML comments
- [ ] No CSS and no JavaScript anywhere

## 💡 Hints

- Use the images in the `images/` folder so your page works without the
  internet: `<img src="images/avatar.svg" alt="...">`.
- Keep every file you make in the `final-project` folder so relative links
  work.
- The starter already has the structure — your job is to fill it with *your*
  content.

## ⭐ Challenge

Create a second page, `contact.html`, and link to it from your navigation.
Put the contact form on that page instead of the main page. (Use the
[links lesson](../05-links/README.md) to refresh your memory on relative
links.)

## ✅ Solution

Open `solution.html` **after** you have finished your own attempt. It is one
example of a complete personal website — compare it with yours and learn from
the differences.
