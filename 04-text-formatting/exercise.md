# Exercise — A Formatted "About Me" Page

## 🎯 Goal

Demonstrate text formatting on a real page: write an "About Me" page that uses
at least six different formatting elements in meaningful ways.

## 📚 What You Learned

- `<strong>`, `<em>` (semantic) and `<b>`, `<i>`, `<u>` (presentational)
- `<mark>`, `<small>`, `<del>`, `<ins>`
- `<sub>`, `<sup>`
- Semantic vs. presentational choice

## 📝 Task

1. Create a new file called `about-me.html` with a complete HTML document.
2. Write an "About Me" page about a topic you enjoy (a hobby, a pet, your
   hometown, your studies…). Use formatting where it *fits the meaning*, for
   example:
   - `<strong>` for something you really care about
   - `<em>` for emphasis on a word or phrase
   - `<mark>` for an important date or deadline
   - `<del>` and `<ins>` to show a change (for example an old and a new fact)
   - `<sub>` or `<sup>` for a real formula, year, or measurement
   - `<small>` for a footer note at the bottom
3. Use at least **one** of `<b>` or `<i>` for a purely visual effect, and add a
   comment explaining *why* you chose semantic or presentational tags there.

## Requirements

- [ ] The page is a complete, valid HTML document
- [ ] It uses `<strong>` at least once
- [ ] It uses `<em>` at least once
- [ ] It uses `<mark>` at least once
- [ ] It uses `<del>` and `<ins>` together at least once
- [ ] It uses `<sub>` **or** `<sup>` at least once
- [ ] It uses `<small>` at least once
- [ ] It uses `<b>` or `<i>` at least once, with a comment explaining your choice
- [ ] All elements have matching closing tags

## 💡 Hint

Choose one real fact from your life and build the page around it. For example:
"I started learning the guitar in <mark>2023</mark> and practice <em>every
day</em>." Real content makes the formatting choices obvious.

## ⭐ Challenge

Add a short "School grades" sentence using `<sup>` (for example
"grade: 9<sup>th</sup>") and a "Favorite quote" paragraph that uses `<strong>`
for the most important words of the quote.

## ✅ Solution

Open `solution.html` **after** you have attempted the exercise. Your page does
not need to match — it just needs to use the elements meaningfully.
